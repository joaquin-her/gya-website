## Proceso:
1. Crear un issue con titulo y descripcion de la tarea. Se puede utilizar inteligencia artificial para extender las indicaciones. Luego ese mismo issue es agregado al backlog del project y puede ser agregado a una Iteracion.
2. Seleccionar una tarea de la iteracion "en curso" en el apartado de Project y trasladarla a "In Progress"
3. Una vez finalizada la tarea trasladarla a "Done" donde será cerrada automaticamente
4. En caso de ser una tarea "en progreso" se pueden hacer commits con las palabras clave 'connect', 'connected to', 'relate', 'relates to', 'related to' para referirse a un issue utilizando posteriormente #123 con el numero de issue. 
5. Tambien es posible cerrar los issues commiteando con las palabras claves 'closes #123' o 'fixes #123', con los numeros de issue
